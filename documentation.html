Guides & support

Documentation

An introduction to Rivendell DJ Air's main interfaces, based on the current development build. These guides explain what is visible in the application; they are not a substitute for release-tested installation or station operating procedures.

DJ Air remains in development. Public installers and verified production setup instructions are not yet available. Avoid testing unverified controls on a live broadcast.

Presenter guides

INTERFACE OVERVIEW

LIVE ON AIR

The Live On Air workspace presents current and upcoming programme information, timing, playout controls and remote microphone controls.

  1. Review the on-air state and the current and next items before taking action.
  2. Check the studio and microphone indicators before attempting a live microphone session.
  3. Use playout and microphone controls only when authorized and familiar with the station's operating procedure.

Microphone connection, monitoring, and failover procedures remain under verification.

VOICE TRACKING

The voice-tracking studio combines a broadcast schedule, a playlist and a three-lane editor for outgoing song audio, presenter voice and incoming song audio.

  1. Choose the authorized service, date, hour and daily log.
  2. Select the intended programme item from the playlist.
  3. Review the outgoing and incoming waveforms and voice-track positioning.
  4. Use the recording, preview, trim and save controls according to your assigned permissions.

Publishing behavior, recovery and production-safe editing procedures are still being verified.

INTERFACE OVERVIEW

AUDIO LIBRARY

The library provides cart browsing, search and filtering, audio metadata and loudness information. Available editing actions depend on user permissions and the installed build.

  1. Use Group, Scheduler Codes or Search to locate an audio cart.
  2. Select a cart to review its information and available actions.
  3. Review loudness readings and gain settings before making any changes.

Gain-based normalization and undo behavior require workflow-specific verification before production use.

INTERFACE OVERVIEW

AUDIO UPLOADER

The bulk audio upload interface displays selected files, destination group, scheduler code, per-file import status and overall progress.

  1. Select or drop audio files into the upload area.
  2. Review the destination group and scheduler code.
  3. Check the file list before starting an import.
  4. Monitor each file's result; do not assume the batch succeeded solely because processing finished.

Use a non-production test group while import behavior is being validated.

ACCESSIBILITY

Presenter preferences include screen-reader announcements, text size, interface magnification, contrast, reduced motion and visual alerts. Individual presenter overrides can take priority over site defaults.

Review the available controls from the Accessibility interface and choose settings appropriate for your display and operating needs.

USER MANAGEMENT

The Administration interface includes presenter account creation and Rivendell rights such as production, traffic, on-air and podcast permissions.

Administrators should review rights carefully and grant only those needed for a presenter's assigned work. Service, group and podcast-feed assignment controls may vary by build.

BACKUP & RESTORE

The current application recovery interface shows backup history, destination information, verification status, download and restore-review actions. Verified restoration and database recovery procedures are not yet published.

Do not perform a restore on a live station based solely on the interface overview.

SYSTEM HEALTH & TROUBLESHOOTING

The diagnostics interface displays observed component connectivity, system resources, audio routing, monitoring status and support-package controls.

A HEALTHY API connection does not establish that audio is reaching listeners. UNVERIFIED and NOT CONFIGURED readings should not be interpreted as confirmed failures. Detailed troubleshooting and measurement guidance remain under verification.
