# Rivendell DJ Air — Public website

Official public-facing GitHub Pages website for the Rivendell DJ Air browser-based broadcasting workspace.

**Website:** https://rivendelldjair.github.io/rivendell-dj-air-website/

## Contents
- Home: project introduction and application areas
- Features: current application areas and clearly labeled work in development or verification
- Screenshots: reviewed development screenshots, with pending features left as placeholders
- Documentation: installation, operation, recovery and release documentation pending verification
- Downloads: no public installer until the approved release is ready

## Website design
The website follows the DJ Air Administration palette: solid navy background `#101722`, panel color `#192435`, muted gold accents `#B48A38` and light text `#EDF2F8`. The main stylesheet is `assets/css/site.css`.

## Publishing
GitHub Pages serves the `main` branch from the repository root. Changes to HTML and CSS are committed to this repository; published updates may require a browser hard refresh.

## Screenshots
The gallery references reviewed PNGs in the repository root. Do not publish screenshots containing credentials, private addresses, or sensitive station details. Additional screenshots will be added as application work is verified.

## Release safety
No public installer is offered yet. Do not publish unapproved builds, checksums, installation claims or release guarantees. The public website is separate from the installed DJ Air application.
