# Rivendell DJ Air — GitHub Pages website

Public static website for the Rivendell DJ Air project.

## Publish
Upload the **contents of this folder**, not the folder itself, to the root of the `main` branch of `RivendellDJAIR/rivendell-dj-air-website`. Replace the existing `index.html`. GitHub Pages source: `main` / `(root)`.

## Design provenance
The carbon-fiber background and colors come from the user-provided read-only DJ Air design export. Original exported CSS copies are retained in `assets/css/` for reference. `site.css` adapts the original look for a public website. No application scripts, authentication logic or private configuration are included.

## Release safety
Downloads are intentionally disabled pending Gold Master acceptance. Screenshot placeholders are intentional to prevent disclosure of private station details.
